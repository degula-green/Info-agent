# 服务三树优先检索与会话上下文实施记录

## 本轮完成

- AI 有知识库范围时默认走 Entity Tree；会话语义或明确时间问题走 Session Tree；显式 `tree_types` 保持优先。
- 增加年月日、本周、本月、最近和显式时间参数解析，按 `Asia/Shanghai` 解释并以 UTC 过滤。
- Entity Tree 命中后通过 Fact 来源获取直接 Chunk，并按会话、时间窗口补充邻近 Chunk；每条证据再次执行 ACL 检查。
- Fact 仅作为树导航元数据，AI Prompt 正式证据统一使用授权后的 Chunk；引用标记 `direct_evidence`/`neighbor`、树路径和 Fact ID。
- Entity 无命中时仅在当前知识库/组织范围内进行 Chunk 降级；无知识库范围时跳过 Tree，保留传统 Chunk 检索。
- `quick/deep` 保留，deep 只扩大树候选和上下文窗口，不再触发全库并行 fusion。
- Tree API 增加自动路由、时间参数、会话参数、`context_chunks`、`routing` 和上下文诊断；保留旧 `retrieval_mode`。
- PG 新增 `observed_at` 迁移字段和时间索引；Fact ES Mapping 增加观测时间、会话组、消息字段。
- 新增路由、时间、直接证据/邻近上下文回归测试。
